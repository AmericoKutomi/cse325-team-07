# Initial Project Ideas

## 1. Personal Task & Goal Tracker

A Blazor web application that allows users to create and manage personal goals and tasks. Users can track progress, set deadlines, mark tasks as completed, and organize tasks by goals. The application will include user authentication and CRUD functionality.

## 2. Equipment / Asset Manager

A Blazor web application for managing equipment and other assets. Users can register, view, update, and remove equipment, track its status and location, and record equipment assignments. The application will include user authentication and CRUD functionality.
